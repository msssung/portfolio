# MINSUNG's Portfolio

사람과 AI를 잇는 엔지니어, 김민성의 개인 포트폴리오입니다.

🔗 링크: https://portfolio-sigma-amber-0bmlynev98.vercel.app/

## 소개

RAG 파이프라인과 MLOps/LLMOps에 관심 있는 AI 엔지니어 지망생입니다. AI 모델이 실제 서비스에서 안정적으로 동작할 수 있도록 개발부터 배포까지 함께 고려하는 엔지니어를 목표로 하고 있습니다.

## 기술 스택

- **AI/ML**: RAG, Dify, Prompt Engineering, LangChain, scikit-learn, Pandas, NumPy
- **Backend**: Python, FastAPI
- **Infra**: Git & GitHub, Docker, Linux, Kubernetes

## 프로젝트

- **AI 기반 K8s 모니터링 플랫폼** - Kubernetes 클러스터 이상 탐지 및 RAG 기반 LLM 분석 플랫폼
- **AI 기반 기사 큐레이션 서비스** - Dify + Milvus 기반 RAG 파이프라인 AI 서비스
- **한국인 삶의 만족도 분석** - KOWEPS 공공 복지 데이터 기반 EDA 및 ML 예측

## 개발 환경

- Tailwind CSS
